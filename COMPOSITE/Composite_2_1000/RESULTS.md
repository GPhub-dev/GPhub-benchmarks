# Composite_2_1000 · Composite plate, m = 2, n = 1000

m = 2 ply angles, n = 1000 training points, 19000 test points, Gaussian kernel, constant trend. Harmonized specification (see [`_scripts/README.md`](../../_scripts/README.md)).

Libraries (10): `DACE`, `egobox-gp`, `GPflow`, `GPML`, `GPstuff`, `GPyTorch`, `OpenTURNS`, `SMT`, `tinygp`, `UQLab`.
