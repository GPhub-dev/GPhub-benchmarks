# Composite_2_200 · Composite plate, m = 2, n = 200

m = 2 ply angles, n = 200 training points, 19800 test points, Gaussian kernel, constant trend. Harmonized specification (see [`_scripts/README.md`](../../_scripts/README.md)).

Libraries (10): `DACE`, `egobox-gp`, `GPflow`, `GPML`, `GPstuff`, `GPyTorch`, `OpenTURNS`, `SMT`, `tinygp`, `UQLab`.
